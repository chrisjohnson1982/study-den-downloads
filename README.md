# Study Den downloads

Study Den is a home practice app for Year 5: maths, English, French, geography, science and history, with coins and rewards set by a grown-up.

## Get the latest version

**[⬇ Download for Android](https://github.com/chrisjohnson1982/study-den-downloads/releases/latest/download/StudyDen.apk)** · **[⬇ Download for Windows](https://github.com/chrisjohnson1982/study-den-downloads/releases/latest/download/StudyDen-Windows.zip)** · [All versions](https://github.com/chrisjohnson1982/study-den-downloads/releases)

### Android
1. Tap **Download for Android** on the phone or tablet.
2. Open the downloaded file. If Android asks, allow installs from your browser.
3. Tap **Install** (or **Update**). Installing over an older version keeps coins, stars and the family link.

### Windows
1. Download and unzip somewhere permanent that OneDrive doesn't sync, such as `%LOCALAPPDATA%\Programs\StudyDen`.
2. Run `maths_den.exe`. If SmartScreen appears, choose **More info → Run anyway**.

The app does nothing until it joins a family with a code from a grown-up's device. This repository holds downloads only; the app's code is kept private.
