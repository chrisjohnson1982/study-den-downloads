# Study Den downloads

Study Den is a home practice app for Year 5: maths, English, French, geography, science and history, with coins and rewards set by a grown-up.

## Get the latest version

**[⬇ Download for Android](https://github.com/chrisjohnson1982/study-den-downloads/releases/latest/download/StudyDen.apk)** · **[⬇ Download for Windows (installer)](https://github.com/chrisjohnson1982/study-den-downloads/releases/latest/download/StudyDen-Setup.exe)** · [All versions](https://github.com/chrisjohnson1982/study-den-downloads/releases)

### Android
1. Tap **Download for Android** on the phone or tablet.
2. Open the downloaded file. If Android asks, allow installs from your browser.
3. Tap **Install** (or **Update**). Installing over an older version keeps coins, stars and the family link.

### Windows
1. Download **StudyDen-Setup.exe** and open it. No administrator password is needed.
2. If SmartScreen says it "protected your PC", choose **More info → Run anyway**. It appears because the app isn't from the Microsoft Store.
3. Follow the steps. Study Den goes in the Start menu (and on the desktop if you tick the box), and can be removed from **Settings → Apps**.
4. Running a newer installer later upgrades it in place and keeps the family link.

Prefer no installer? The [zip version](https://github.com/chrisjohnson1982/study-den-downloads/releases/latest/download/StudyDen-Windows.zip) runs from any folder: unzip it and open `maths_den.exe`.

The app does nothing until it joins a family with a code from a grown-up's device. This repository holds downloads only; the app's code is kept private.
